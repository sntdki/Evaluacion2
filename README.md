   # Evaluacion2

   ## Descripción
   Script Python para calcular rutas con la API GraphHopper Directions.

   ## Funcionalidades
   - Interacción e instrucciones en español.
   - Distancia y duración con máximo dos decimales.
   - Salida mediante «s» o «salir».

   ## Requisitos
   - Python 3
   - Paquete requests
   - API Key de GraphHopper

   ## Ejecución
   1. pip install requests
   2. export GRAPHHOPPER_API_KEY="su_clave"
   3. python3 graphhopper.py
